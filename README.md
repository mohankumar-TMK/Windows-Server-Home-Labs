# Windows-Server-Home-Labs

Home labs for Windows Server 2025, Active Directory, DHCP, DNS, and other core IT infrastructure skills.

This repository documents my hands-on lab work as part of my preparation for an entry-level IT job. The labs focus on Windows Server administration, networking, and systems configuration.

---

## 💻 Lab Index

| Lab # | Title                                              | Topics Covered                                                        |
|-------|-----------------------------------------------------|------------------------------------------------------------------------|
| 01    | Windows Server 2025 Installation                    | ISO setup, VirtualBox VM config, initial server setup                 |
| 02    | Rename Server & Install Active Directory            | Server renaming, AD DS role install, domain setup                     |
| 03    | Active Directory Account Creation, Cmd Commands     | Adding and copying users in AD, common Cmd/PowerShell commands        |
| 04    | Multiple Domain Controllers & Replication           | Adding a secondary DC, verifying AD replication                       |
| 05    | DHCP Server Configuration                           | Scopes, lease durations, reservations, exclusions                     |
| 06    | DNS Management                                      | Forward/reverse lookup zones, A/PTR records, troubleshooting          |
| 07    | Group Policy Objects (GPOs)                         | Creating and linking GPOs, password policy, login scripts             |
| 08    | NTFS Permissions & File Sharing                     | Shared folders, permission inheritance, access troubleshooting        |
| 09    | PowerShell Automation                               | Bulk user creation via CSV, basic system monitoring scripts           |

> More labs will be added as I continue building out the environment.
